# Vexel

Векторный редактор для мобильных интерфейсов в стиле Material 3 Expressive. Jetpack Compose, Material3 1.4.0.

## Что внутри
- **Проекты** - сетка карточек с превью, создание (пресеты холста), переименование, дублирование, удаление, автосохранение (JSON в `filesDir/projects`).
- **Редактор** - жесты: перенос, ресайз за ручки, поворот (шаг 15 deg), щипок-зум, пан; умные направляющие; undo/redo; группы; слои (видимость, блокировка).
- **Фигуры MD3** - свои реализации форм `MaterialShapes` (cookie, burst/sunny, clover, flower, heart...) + звёзды и многоугольники. Смена фигуры у слоя идёт с морфингом.
- **Выравнивание** - по краям/центру относительно выделения или холста, равные промежутки, одинаковая ширина/высота, центр холста.
- **Компоненты MD3** - заготовки (кнопки, FAB, карточка, чип, switch, radio, checkbox, slider, progress, divider, badge, search, list item, tabs, segmented, snackbar, dialog, app bar, nav bar, поле ввода).
- **Экспорт** - PNG (2x) и чистый SVG.

- **Объект внутри компонента** - тап по уже выбранному компоненту (или по слою в панели 'Слои') выбирает один объект внутри него.
- **Свои картинки и шрифты** - '+' -> 'Основа' -> 'Картинка'; шрифт (.ttf/.otf) - в панели 'Стиль' у текстового слоя. Встраиваются в SVG.
- **Булевы операции** - кнопка в панели над выделением: объединение, разница, пересечение, исключение, объединить, разделить, объединить слои (в картинку). Результат - слой PATH.

- **Тон проекта** - 'Стиль' без выделения (или меню Menu > 'Тон проекта...'): базовая схема, от своего цвета или с обоев (Material You), светлая/тёмная. Цвета, выбранные из палитры, и все компоненты следуют тону и перекрашиваются сами; 'свой цвет' остаётся фиксированным.
- **Выдвижная панель** - тяните пилюлю над выделением вверх (или нажмите на ручку): шрифт, размер, цвет, обводка, прозрачность, действия.

## Как добавить свою фигуру
`shapes/ShapeLibrary.kt`, блок `init`, одна строка:

```kotlin
add("my-star", "Моя звезда", STARS) { RoundedPolygon.star(7, innerRadius = 0.6f, rounding = CornerRounding(0.2f)) }
```
Нужна другая категория - добавьте константу и внесите её в `categories`.

## Структура
- `data/` - модель (`Node`, `Project`), выравнивание, привязки, геометрия (чистый Kotlin, без Android), хранилище.
- `shapes/` - библиотека фигур.
- `render/` - отрисовка слоёв, экспорт PNG/SVG.
- `ui/theme` - схемы Vexel (светлая/тёмная/динамическая), типографика, пружины `Motion`.
- `ui/editor` - состояние, холст с жестами, панели, экран.
- `ui/projects` - экран проектов.

## Языки

Все тексты - в `app/src/main/assets/lang/*.json` (`en.json` - базовый, `ru.json`).
**Новый язык:** скопируйте `en.json` в `de.json`, поменяйте `"_name"` и переведите значения (ключи и `{0}` не трогайте).
Файл подхватится сам и появится в Настройки -> Язык. Без пересборки можно добавить файл кнопкой '+ Язык'
или положить в `Android/data/com.qwenz.qwel/files/lang/`. Нет ключа в языке - берётся английский.
В коде: `tr("key")`, `tr("key", arg0, arg1)`. Имена фигур: ключ `shape.<id>`, категории - `cat.<id>`.

## Шрифты

Встроен Figtree (OFL) - это шрифт интерфейса и семейство для текстовых слоёв (встраивается и в SVG).
Свои семейства: положите `assets/fonts/<Семейство>-<Regular|Medium|Bold...>.ttf`, они появятся в выборе шрифта.
Шрифт интерфейса задаёт `Fonts.UI_FONT`. Figtree без кириллицы - русские буквы рисуются системным шрифтом.

## Производительность

Для замера скорости ставьте release-сборку: debug-сборка Compose заметно медленнее.

## Обучение и подсказки

Первый запуск: приветствие -> обзор всех возможностей (6 экранов) -> практика жестов на пробном листе.
Дальше по ходу работы показываются подсказки: каждая один раз, когда впервые оказываетесь в нужном месте
(лист, выбор слоя, панели 'Добавить'/'Стиль'/'Выравнивание'/'Слои', режим 'Выбор', экран проектов).
Подсказки отключаются в Настройках; 'Пройти обучение заново' возвращает и обучение, и подсказки.
Новая подсказка: `hints.show("id")` в нужном месте + ключи `h_id_t` / `h_id_b` в assets/lang.

## Жесты и обучение

При первом запуске - приветствие и обучение на пробном листе: каждый жест делаете сами, шаг засчитывается, когда получилось.
Любой шаг можно пропустить, а жест - отключить прямо там. Потом всё то же: Настройки -> 'Жесты и обучение'
(переключатели по одному + 'Пройти обучение заново'; то же в меню three-dot редактора). Отключённый жест не срабатывает совсем.

Базовые (нельзя отключить): тап, перетаскивание, масштаб двумя пальцами.
Отключаемые: тап двумя пальцами - отменить | тремя - вернуть | двойной тап по листу - вписать в экран |
двойной тап по слою - править/'Стиль' | долгое нажатие на листе - 'Добавить', на слое - 'Стиль' | свайп вниз по шапке панели.
Новый жест = значение в `enum Gesture` + ключи `g_*` в assets/lang.


## Размытие фона и стеклянные панели

- У слоя есть 'Размытие фона' (панель 'Стиль' и быстрый инструмент в доке). Размывается всё, что лежит под слоем; чтобы вышло матовое стекло, сделайте заливку полупрозрачной.
- Панели редактора (тулбар, док, нижняя панель) размывают холст под собой. Выключается в настройках: 'Стеклянные панели'.
- Ограничения: живое размытие и стеклянные панели только на Android 12+ (API 31); в PNG размытие есть на любом Android; в SVG размытия нет; в превью карточек проектов его нет; одновременно живьём размываются до 8 слоёв (остальные рисуются без размытия).

### v11
- Групповое масштабирование: при выборе нескольких слоёв на углах общей рамки появляются ручки. Потяните за угол, и все слои растут или уменьшаются вместе (пропорционально, от противоположного угла): вместе с размером масштабируются скругления, обводка, размытие, тень и размер шрифта.
